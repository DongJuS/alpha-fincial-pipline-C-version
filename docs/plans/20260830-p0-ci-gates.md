# Phase 0 continuous-integration gates

## Goal

Automate the reproducibility, formatting, static-analysis, dev-sanitizer, and
optimized-bench gates already proven locally. CI must fetch the exact Python
reference commit and fail if required floating-point or sanitizer flags drift.

## Files

- `.github/workflows/ci.yml`
- `tools/verify_build_flags.py`
- `tests/test_build_flags.py`
- `progress.md`

## Contract

Satisfies the CI requirements in `docs/BUILD_AND_TEST.md` and
`docs/plans/phase-0-scaffold.md`. It does not add runtime dependencies.

## Tests

- Workflow YAML parses and pins the Python source SHA.
- Build-flag verifier accepts current dev/bench compile databases.
- Unit tests prove missing sanitizer/FP flags and fast-math are rejected.
- Local Python tests, dev/bench builds, ctest, format, and clang-tidy remain green.

## Risks / open questions

- The first hosted run requires pushing the commit; local validation proves workflow
  structure and all invoked commands, but cannot substitute for GitHub runner state.
- Rust CI remains conditional until the Phase 0 workspace boundary is created.
